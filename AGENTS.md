# AGENTS.md

This file provides guidance to Codex (Codex.ai/code) when working with code in this repository.

## Project Overview

**Dreaming Railway** is a 2D side-scrolling Unity game (URP, 2022.3+) with a dual-world mechanic. The player rides a subway, fights off sleep by slapping themselves, and when tiredness maxes out they fall into a dream platformer. The goal is to survive all transfer stations across 5 days (plus an infinite mode).

**Scenes**: MainScene → StageSelectScene → SubwayScene ↔ DreamScene (ScriptScene and TutorialScene overlay as additive loads)

## Unity / Build

There are no custom build scripts. Open the project in Unity 2022.3+ and build via **File > Build Settings**. The target resolution is 1920×1080. Key packages: URP 17.3, TextMesh Pro, New Input System 1.18.

## Architecture

### Manager Singleton Pattern

All global managers inherit `SingletonManagers<T>` (`Assets/Scripts/Core/Managers/Base/`), which handles `DontDestroyOnLoad` and auto-creation. Managers implement `IManager` with an `Init()` method.

Initialization order (driven by `ManagerInitializer`):
```
GameManager → SoundManager → UIManager → TimerManager → SubwayFlowManager
```

Access pattern everywhere: `GameManager.Instance`, `UIManager.Instance`, etc.

### TimerManager — Global Pause & Play Time

`TimerManager` tracks `playTime` (shown on the GameOver/GameClear results screens) and exposes a global pause flag (`IsPaused`) via `StopTimer()/StartTimer()`. Per-frame gameplay systems (`SubwayFlowManager`, `TirednessManager`, `SubwayPlayerContext`) each run their own `Update()` and guard it with `if (TimerManager.Instance.IsPaused) return;` — there is no central tick-dispatch interface; `StopTimer()` is used specifically where a popup (GameOver/GameClear) needs gameplay frozen without touching `Time.timeScale` (which would also freeze the popup's own fade-in). Full freezes that should also stop animations/coroutines use `GameManager.StopGame()/ResumeGame()` (`Time.timeScale = 0`) instead.

### GameManager — Global State

Holds `GameMode` (None / Tutorial / NormalMode / InfiniteMode), `CurrentDay` (1–5), `MaxClearDay` (saved progression), and `IsGameStopped`. Call `GameManager.Instance.StartDay(day)` to begin a day.

### SubwayScene Dependency Injection

`SubwaySceneManager` (execution order −100) serves three roles in one class:

1. **레퍼런스 컨테이너** — `[SerializeField]`로 씬 내 컴포넌트 레퍼런스를 보유 (SubwaySceneRefs 역할)
2. **DI 코디네이터** — `Start()`에서 각 시스템의 `Init()`을 올바른 순서로 호출하여 의존성을 주입
3. **드림씬 단일 진입점** — SubwayScene → DreamScene 전환은 반드시 이 클래스의 이벤트 구독을 통해서만 발생

```csharp
// Start()에서 순서대로 초기화 및 주입
tirednessManager.Init();
stationManager.Init();
subwayPlayerContext.Init(tirednessManager);

// 꿈속 진입 이벤트를 단일 지점에서 처리
TirednessManager.OnTiredMaxed += MoveToDreamScene;
subwayPlayerContext.OnStateChanged += MoveToDreamScene; // DEEPSLEEP 상태 필터
```

`MoveToDreamScene()`은 진입 전처리(피로도 조정, 흐름 속도 변경)와 `SceneTransitionManager.Instance.GoToDream()` 호출을 순서대로 담당한다.

### Tiredness System

`TirednessManager` accumulates `CurrentTired += deltaTime` each tick. At 100 it fires `OnTiredMaxed`. Slapping costs −3 (normal) / −4 (infinite) points with a 5-second cooldown enforced by `SubwayRuleManager`. After returning from dream, tiredness is divided by 2 if dream time < 100 s, or multiplied by 1.5 if > 100 s.

### Subway Flow (SubwayFlowManager)

Runs as a state machine via `Tick()`. Alternates between travelling (`IsStopping = false`) and stopped at station (`IsStopping = true`). Station data (travel time 10–15 s, stop time 6–8 s) is generated by `StationManager.GenerateSubwayLines()` based on the current day. Transfer station count: `day + 1` in normal mode, 99 in infinite mode. Missing a transfer fires `OnSubwayGameOver`.

### SubwayRuleManager

Enforces subway game rules as an `ITickable`. Key responsibilities:
- **Slap mechanic**: `TrySlap()` reduces tiredness by 3 (normal) / 4 (infinite) with a 5-second cooldown. Exposes `IsSlapCoolTime` and `CurrentSlapCooldown` as static properties.
- **Standing mechanic**: `TryStanding()` forces tiredness to 100 immediately. After standing, the player cannot stand again until 2 more stations pass (`StandingCount` tracks this).
- **Transfer detection**: Checks if the player boards at transfer stations; missed transfer → fires `OnSubwayGameOver`.

### Player State Machine (SubwayPlayerContext)

Three states implementing `ISubwayPlayerState`:
- **PlayerSleepState** — default; tiredness accumulates
- **PlayerStandingState** — immediately forces `TirednessManager.CurrentTired` to 100, plays `isStanding` animation, triggers `StandingSFX()`
- **PlayerDeepSleepState** — triggers dream scene load via `SubwaySceneManager`

State changes go through `SubwayPlayerContext.ChangeState()` which calls `Exit()` then `Enter()`. `AnimationEventHandler` (`Assets/Scripts/Content/Player/AnimationEventHanlder.cs`) bridges Unity animation events to player state callbacks.

### UI Framework

All UI inherits from `UI_Base` (`Assets/Scripts/Content/UI/Base/`). The binding system maps child GameObjects to enum-named entries:

```csharp
Bind<Button>(typeof(Buttons));      // binds by enum name matching GameObject name
Button btn = GetButton((int)Buttons.StartButton);
```

`UI_Popup` is stack-managed by `UIManager` (`ShowPopupUI<T>(name)` / `ClosePopupUI()`). `UI_Scene` is a single persistent overlay per scene (`ShowSceneUI<T>(name)`). All UI prefabs live under `Resources/Prefabs/UIs/`.

### DreamManager

Singleton (`Assets/Scripts/Content/Dream/DreamManager.cs`) that owns dream-scene state: `isInDream`, `DreamTimeSpeed`, `isGameOverInDream`. Listens to `SceneManager.sceneLoaded` to initialize dream UI and map spawners (`MapXSpawn`, `MapYSpawn`, `FogMovement`, `WhitePanelSpawn`). In tutorial mode, coordinates with `TutorialManager` to gate dream progression.

### Dialogue & Tutorial

**ScriptManager** (`Assets/Scripts/Content/Dialogue/ScriptManager.cs`): Loads per-day story text as `DialogLine` structs (Text + Emotion fields). Shows `UI_ScriptPopup` at day start and after clearing. Emotion sprites are loaded from `Resources/`.

**TutorialManager** (`Assets/Scripts/Content/Tutorial/TutorialManager.cs`): Drives multi-phase tutorial (Subway, Dream, GameOver phases) via progression indices (e.g., `slapIdx=12`, `standingIdx=16`, `enterDreamIdx=19`). Controls tutorial popup visibility and overlays. Uses additive scene loading for `TutorialScene` and `ScriptScene`.

### SoundManager

Separate `AudioSource` components for BGM and SFX. Clips are cached by name and loaded from `Resources/Sounds/BGM/` and `Resources/Sounds/SFX/`. Volume and mute state are synced with `SaveManager` (PlayerPrefs keys: `BGM_VOLUME`, `SFX_VOLUME`, `BGM_MUTE`, `SFX_MUTE`). Use the typed helper methods (`PlayBGM()`, `SlapSFX()`, `JumpSFX()`, etc.) rather than raw Play calls.

### SaveManager

Thin wrapper around Unity `PlayerPrefs`. PlayerPrefs keys: `MaxClearStage`, `BGM_VOLUME`, `SFX_VOLUME`, `BGM_MUTE`, `SFX_MUTE`. Use typed methods (`LoadMaxClearDay()`, `SaveMaxClearDay()`, `LoadBgmVolume()`, etc.) rather than direct PlayerPrefs calls.

## Key Data Structures

| Type | Location | Purpose |
|------|----------|---------|
| `SubwayLineData` | StationManager | List of `StationData`, transfer index, hasDestination flag |
| `StationData` | StationManager | `stationType` (Normal/Transfer/Destination), `travelTime`, `stopTime` |
| `DialogLine` | ScriptManager | `Text` + `Emotion` fields for per-day story dialogue |

> **Static properties pattern**: `TirednessManager` and `SubwayRuleManager` expose key values (`CurrentTired`, `MaxTired`, `IsSlapCoolTime`, `IsStandingCoolDown`, etc.) as `static` properties for convenient cross-system reads without holding a reference.

## Core Event Flow

**Dream entry**: Tiredness hits 100 → `OnTiredMaxed` → `SubwaySceneManager.MoveToDreamScene()` (tiredness 조정 + flow speed 3–4×) → `SceneTransitionManager.GoToDream()` → `DreamManager` initializes map spawners. DeepSleep 상태 진입 시에도 동일한 단일 경로를 통함.

**Dream exit**: Player touches `ExitDoor` → `WhitePanelSpawn` fades → SubwayScene reloads → flow speed resets → tiredness recalculated based on dream duration.

**Game over (subway)**: Player misses transfer station → `SubwayRuleManager.OnSubwayGameOver` → `UI_GameOverPopup2` shown.
